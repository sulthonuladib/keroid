JetBrains Mono Nerd Font

Source: https://github.com/egoist/kero/tree/v2.1.21/resources/fonts
Kero source commit: d6810859d9136b6729a3d7c59779c5648d65fe3b

The regular, bold, italic and bold-italic TTF files in res/font are unmodified
copies of desktop Kero's bundled fonts. They include Nerd Font prompt symbols.
Copyright and SIL Open Font License: jetbrains_mono_nerd_OFL.txt in this directory.

These assets are bundled in Keroid; the reference clone is not a build dependency.

Ghostty terminal themes

The colour table in kotlin/.../term/TerminalThemes.kt is generated (see
scripts/gen-terminal-themes.py, which pins the source table's SHA-256) from the
themes Ghostty itself ships, as generated by MyGo from
ghostty-themes-release-20260921-150923-0b55a9e.tgz.

Those themes come from iTerm2-Color-Schemes (https://github.com/mbadolato/iTerm2-Color-Schemes):
